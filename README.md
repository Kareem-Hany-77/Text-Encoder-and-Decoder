# Text Encoder & Decoder (C++)
- A simple program built with C++ and Data Structures that encodes and decodes text.  

---------------------------------------------------------------------------------------

## Features
- Convert symbols (e.g., #) to letters (e.g., A).
- Convert letters (e.g., A) back to symbols (e.g., #).

---------------------------------------------------------------------------------------

## How to Run
- Open Text-Encoder-and-Decoder.cpp in any C++ IDE or compiler.
- Compile and run the program.
- Choose the desired mode from the menu.
